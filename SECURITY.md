# Security reporting

Do not post passwords, private keys, precise private locations or sensitive message contents in public issues or relay rooms.

Use this repository’s private vulnerability-reporting facility if it is enabled. Otherwise, agree on a private reporting channel with the maintainer before sending sensitive details. A public relay room or ordinary GitHub issue is not a private reporting channel.

For general, non-sensitive bugs and support, see [README.md](README.md). Include the affected version, platform, reproduction steps and a description of the impact. Review and redact diagnostic files before sharing them.

Release maintainers must configure and verify the private reporting destination before publication. No inherited upstream contact should be assumed to accept neXt security reports.
