# Meshchat neXt 0.1.0-preview.1

Local review preview combining independent Reticulum/RNode and MeshCore connections. Includes MeshCore direct messages, channels, explicit contact linking, announces, room/repeater controls, notifications, backups, and optional Radio2 configuration. Outgoing channels show radio acceptance and heard-repeat counts; direct messages additionally retain delivery acknowledgments.

The name, N artwork, application ID, package namespace, storage paths, and Android backend port are separate from HK. No automatic migration, release upload, or publication is performed. MediaMesh photo/voice transport remains future work; Radio2 configuration alone does not implement it.
